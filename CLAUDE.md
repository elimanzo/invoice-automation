# invoice-automation

## Agent skills

### Issue tracker

Issues and specs live as local markdown under `.scratch/<feature-slug>/` — no remote tracker. See `docs/agents/issue-tracker.md`.

### Triage labels

Default canonical vocabulary, recorded as a `Status:` line in each issue file: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context — one `CONTEXT.md` plus `docs/adr/` at the repo root, both created lazily. See `docs/agents/domain.md`.
